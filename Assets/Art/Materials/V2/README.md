# Impact Theory V2 Material Library

`V2_MATERIAL_LIBRARY.blend` contains reusable Blender material assets for:

- Wood
- Brick
- Stone
- Concrete
- Steel
- Painted Steel (navy, cobalt, orange, and golden-yellow finishes)
- Rubber

The materials are independent of structural geometry. Preview assignments are showcase combinations, not permanent restrictions. Physics properties are intentionally deferred.
